# Seventeen writing characteristics
Choose a few per task. Ground personal preferences in samples; let audience and purpose govern the rest. This is an editorial checklist, not a validated scientific taxonomy.

| Characteristic | Observable instruction |
|---|---|
| 1. Audience knowledge | Retain useful technical language and explain unfamiliar terms. |
| 2. Relationship | Match colleague, stranger, customer, friend or family without invented familiarity. |
| 3. Emotional intent | Aim for reassurance, curiosity, urgency or amusement through real substance. |
| 4. Desired action | Make the intended decision or next step clear when needed. |
| 5. Formality | Match contractions, greetings and vocabulary in relevant samples. |
| 6. Directness | Match how quickly the user states a point or request. |
| 7. Certainty | Preserve fact, belief, possibility and hypothesis distinctions. |
| 8. Specificity | Use authentic details; never create evidence. |
| 9. Agency | Clarify who does what; replace abstract action-nouns when helpful. |
| 10. Vocabulary | Prefer familiar expressions over unnecessary ornate synonyms. |
| 11. Rhythm | Match variation, pauses, long thoughts and short statements. |
| 12. Paragraphs | Match channel, readability and grouping of ideas. |
| 13. Transitions | Connect actual reasoning without repeating the point. |
| 14. Humor | Preserve supported wit without inventing a persona. |
| 15. Analogy | Use scenes that clarify a mechanism; respect important limits. |
| 16. Rhetorical habits | Match questions, asides and repetition without mechanically multiplying them. |
| 17. Endings and presentation | Match closes, punctuation, emojis and actual CTAs to the channel. |

Scene example: explain a delivery delay to a repeat customer who needs a firm plan; acknowledge inconvenience, give the verified new date, ask whether it works. This is more actionable than sound professional and human.
