# Evidence and limits
Research starting points; open originals before detailed claims or quotes. These do not validate this skill as a finished intervention.

- Reinhart et al., PNAS (2025): https://pmc.ncbi.nlm.nih.gov/articles/PMC11874169/ — grammatical/rhetorical differences in tested corpora motivate attention to genre and abstraction. Don't generalize across every model or label words inherently AI-written.
- Wang et al., Findings of EMNLP (2025): https://aclanthology.org/2025.findings-emnlp.532/ — personal style imitation has limits; examples don't guarantee user preference.
- Self-Refine, NeurIPS (2023): https://proceedings.neurips.cc/paper_files/paper/2023/hash/91edff07232fb1b55a505a9e9f6c0ff3-Abstract-Conference.html — selected task improvements don't prove a second reviewer improves personal voice.
- Self-correction survey, TACL (2024): https://aclanthology.org/2024.tacl-1.78/ — examine feedback conditions and limits before prescribing autonomous review universally.

Evaluate on held-out, format-matched tasks. Ask whether the user would say/send the output and track remaining substantive edits. Check meaning independently. AI detection, views and a model judge's preference don't prove naturalness. Never promise no editing ever again.
